# E05-signed-restore (Public Snapshot Subset)

In the v1 public research snapshot, this directory exports only the stdlib-only read-only GDB RSP helper (`rsp_readonly.py`) and its offline unit suite (`test-rsp-readonly.py`, used by [`E05-ctrr`](../E05-ctrr/README.en.md) and `make installed-offline-tests`); live signing and transfer scripts are omitted.
